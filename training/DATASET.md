# 데이터셋 준비 — MVTec AD

## 1. 내려받기 (직접)

1. 공식 페이지: https://www.mvtec.com/company/research/datasets/mvtec-ad
2. 라이선스(CC BY-NC-SA 4.0)에 동의하고 `mvtec_anomaly_detection.tar.xz`(약 5GB)를 받는다.
   카테고리별 개별 파일이 제공되면 아래 카테고리 하나만 받아도 된다.
3. 압축을 풀어 카테고리 폴더들(`metal_nut`, `transistor` …)이 들어 있는 상위 폴더 경로를 확인한다.

> 약관 동의와 다운로드는 직접 해야 한다. 파일 크기·카테고리 구성은 페이지에서 확인할 것(이 문서의 수치는 기억 기반이라 정확하지 않을 수 있음).

## 2. 카테고리 선택

| 후보 | 특징 | 비고 |
|---|---|---|
| `metal_nut` (권장 시작점) | 양품 대비 불량 비율이 높은 편이라 시험셋의 불량 수가 상대적으로 많음 | 평가 지표가 덜 흔들림 |
| `transistor` | 전자부품이라 주제(PCB·전자 외관검사)와 가까움 | 불량 수가 적어 시험셋 불량이 몇 장 안 됨 → 재현율이 크게 흔들림 |

변환 후 스크립트가 **실제 장수**를 출력하므로 그 숫자로 판단한다.

## 3. 변환

```bash
python prepare_mvtec.py --src <압축 푼 폴더> --category metal_nut --out data
```

- `data/good`, `data/defect`가 만들어지고 `data/manifest.csv`에 원본 경로·불량 종류가 남는다.
- 원본의 train/test 구분은 쓰지 않고 `train.py`가 클래스 비율을 유지해 다시 나눈다(seed 고정, `out/split.json`).
- `ground_truth` 마스크는 분류에 쓰지 않으므로 복사하지 않는다.

## 4. 학습

```bash
python train.py --data data --out out --epochs 20
```

## 5. 알아둘 점

- **비상업적 이용 전용**이다. 원본·변환 이미지를 저장소에 올리지 말 것(`.gitignore`에 `data/` 포함). 포트폴리오에는 지표와 화면 캡처를 쓰고 데이터 출처와 라이선스를 명시한다.
- MVTec AD는 원래 "정상만 학습하는 이상 탐지" 벤치마크다. 여기서는 불량 샘플을 일부 학습에 쓰는 **지도 분류**로 바꿔 쓰므로, 논문·리더보드 수치와 비교할 수 없다.
- 이 데이터의 성능은 이 카테고리·촬영 조건에서의 값이며 실제 생산라인 성능을 보장하지 않는다.
- 불량이 매우 작은 카테고리는 224px 리사이즈에서 결함이 사라질 수 있다. 재현율이 낮으면 `--size`를 키우고(앱의 `InputSize`도 같이) 다시 학습한다.
- DeepPCB(PCB 결함 검출)는 이미지 쌍·박스 라벨 구조라 **검출 모델 단계**에서 쓴다. 템플릿(양품)과 시험 이미지가 같은 기판이므로 쓸 때는 기판 단위로 분할해야 누수가 없다.
