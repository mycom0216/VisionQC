# 이미지·데이터 출처와 이용 조건

표지·실제 검사 화면·시연 영상에 보이는 금속 너트 이미지는 MVTec AD의 metal_nut 데이터입니다.

- 제공자: MVTec Software GmbH
- 원본: https://www.mvtec.com/research-teaching/datasets/mvtec-ad
- 라이선스: Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0)
- 이용 조건: https://creativecommons.org/licenses/by-nc-sa/4.0/
- 변경 내용: 표지 자르기, 앱 화면 내 표시, CAM 겹침, 캡처 크기 조정, 영상 설명 자막·편집.

해당 원본 및 그 변경 이미지·영상 부분에는 원 라이선스 조건을 유지합니다. 나머지 프로그램 코드나 독립 문서의 라이선스가 자동으로 같아진다는 의미는 아닙니다. 데이터셋 전체나 학습 모델 원본은 제출용 묶음에 포함하지 않습니다. 상업 이용 판단이 필요하면 제공자의 조건을 확인하세요.

기존 프로젝트의 고정 supervised 분할(335장: train235/val50/test50)을 사용했습니다. 공식 이상탐지 벤치마크 분할·평가 결과가 아니며, 이번에는 기존 시험셋을 다시 검증했습니다.

논문: Paul Bergmann, Michael Fauser, David Sattlegger, Carsten Steger, MVTec AD — A Comprehensive Real-World Dataset for Unsupervised Anomaly Detection, CVPR 2019.
