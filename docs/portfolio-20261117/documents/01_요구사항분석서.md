## 1. 프로젝트 개요
VisionQC는 금속 부품 이미지의 양품·불량 분류, 검사 이력, 작업자 검토, 통계를 한 흐름으로 제공하는 Windows 데스크톱 프로젝트다. C# WPF의 화면·비동기 처리, ONNX 추론, OpenCV 전처리, SQLite 저장과 운영 기능을 함께 구현한다. 목표 사용자는 검사 작업자, 검사 기준을 관리하는 엔지니어, 계정·데이터를 관리하는 관리자다.

목표는 AI 판정만 보여주는 데모를 넘어, 실패를 ERROR로 구분하고 모델 버전·임계값·정정 기록을 추적할 수 있는 검사 도구를 만드는 것이다. 현재는 학습용 시제품이며 실제 생산라인의 검증·인증을 완료한 제품은 아니다.

## 2. 문제 정의와 이해관계자
| 사용자 | 업무상 문제 | 필요한 결과 |
|---|---|---|
| 작업자 | 이미지마다 판정 확인과 기록이 분리됨 | 자동 검사, 분명한 OK/NG/ERROR, 이력 조회 |
| 엔지니어 | 오판 원인과 임계값 영향을 비교하기 어려움 | 점수·모델 버전 추적, 히트맵, 임계값 미리보기·검토 기록 |
| 관리자 | 계정 권한과 데이터 복구 관리 필요 | 역할 제한, 감사 로그, 백업·복원·보존 정책 |
| 평가자·면접관 | 화면만으로 구현 깊이를 판단하기 어려움 | 실행 시연, 아키텍처, 검증 근거와 한계 |

위 문제는 프로젝트 기획 가설이다. 현업 인터뷰나 실제 공장 도입 효과를 측정한 결과는 없다.

## 3. 브레인스토밍
| 발상 축 | 아이디어 | 선택과 이유 |
|---|---|---|
| 입력 | 폴더, 감시 폴더, 영상 파일, 카메라, PLC 트리거 | 폴더·영상 구현. 카메라는 실장비 확인 필요. PLC는 장비 계약 정의 후 |
| AI | 이진 분류, CAM, 객체 검출, 이상 탐지 | 분류+CAM 사용. 박스·유형은 검출 모델 후속 범위 |
| 설명 | 불량 점수, 히트맵, 박스, 정답 비교 | 점수·CAM·검토 이력. CAM을 정답 박스로 소개하지 않음 |
| 품질 관리 | 날짜·판정 필터, 임계값 비교, 정정, CSV | 핵심 기능 구현, 이번에 표시 결과 CSV 추가 |
| 운영 | 권한, 감사, 백업, 복원, 자동 정리, 설치 프로그램 | 권한·백업 구현. 자동 삭제·서명 설치는 후속 |
| 확장 | MES, 원격 대시보드, 모델 등록부, 드리프트 감시 | 단일 PC 시연 이후 확장 후보 |

## 4. 우선순위와 범위
Must: 이미지 검사, 오류 구분, 이력, 로그인·권한, 검토·정정, 통계. Should: CAM, 감시, 영상, 백업·복원, CSV. Could: 검출 박스·유형, 카메라·PLC, MES. 현재 제외: 실시간 제어 보증, 생산 품질 인증, 자동 폐기 결정, 다중 PC 동시 운영.

## 5. 사용자 시나리오
1. 작업자가 로그인하고 폴더와 설정 요약을 확인한 뒤 검사한다.
2. 앱이 이미지별 전처리·추론·판정을 수행하고 결과를 저장한다. 한 장 실패는 ERROR로 남기고 나머지를 계속한다.
3. 작업자는 NG 이력을 조회하고 CAM으로 참고 위치를 확인한다. 조회된 원 판정은 CSV로 전달할 수 있다.
4. 엔지니어는 임계값 변경 영향을 미리 보고 OK/NG 확인·정정을 기록한다. 원 판정은 보존한다.
5. 관리자는 감사 로그와 백업을 확인한다. 복원·삭제는 별도 확인 절차를 거친다.

## 6. 핵심 정책
불량 점수 ≥ 임계값이면 NG. NaN·무한대·손상 이미지는 ERROR. 양품률은 OK/(OK+NG)이며 ERROR는 분모에서 제외한다. 정정은 추가 이력이며 원 판정을 수정하지 않는다. 모델 식별은 파일 SHA-256의 앞 12자리다. 날짜는 화면의 로컬 날짜를 UTC 저장 범위로 변환한다.

## 7. 위험과 대응
| 위험 | 대응 | 잔여 한계 |
|---|---|---|
| 작은 데이터·분할 편향 | 고정 분할과 혼동행렬 공개 | 다른 공장·조명 일반화 미검증 |
| CAM을 검출로 오해 | 7×7 참고 위치라고 화면·발표에 표기 | 정확한 경계·유형 불가 |
| 이미지 경로만 저장 | 파일 보존·백업을 운영 절차에 포함 | DB만 복원하면 이미지 복원 안 됨 |
| 계정·DB 파일 유출 | 해시 저장·권한·로컬 시연 격리 | OS 파일 접근 통제·암호화 별도 필요 |
| 내보내기 범위 오해 | 표시된 원 판정 최대 500건 명시 | 전체 DB·정정 판정 내보내기는 별도 기능 |
