작성일 2026-11-13 · 버전 1.0 · 입력: [01_분석서](01_분석서.md) §4~5, [02_설계서](02_설계서.md)
상태 기준일: 2026-11-13 커밋 `6173822`

> 분석서의 요구사항 ID(FR-01~14)를 그대로 쓰고, 각 항목에 **입력·처리·출력·수용 기준·현재 상태·검증 방법**을 붙였다.
> 상태: **구현**(코드+테스트) / **부분**(일부만) / **미구현**.

## 1. 기능 요구사항

### FR-01 이미지 입력 — 부분
| 항목 | 내용 |
|---|---|
| 입력 | 폴더 경로 (jpg·jpeg·png·bmp·tif·tiff, 이름순) |
| 처리 | 폴더 내 이미지를 순서대로 공급. 폴더가 없으면 작업 `Failed` |
| 출력 | `ImageFrame` 스트림 |
| 수용 기준 | 이미지가 아닌 파일은 무시, 빈 폴더는 0장으로 정상 종료, 없는 폴더는 오류로 종료 |
| 상태 | **폴더 입력 구현**. 단일 파일·USB 카메라·하위 폴더 UI 옵션은 미구현 |
| 검증 | `Folder_source_*` 테스트 2건, `Source_failure_marks_job_failed` |

### FR-02 이미지 소스 추상화 — 구현
`IImageSource` 인터페이스. 소스를 바꿔도 파이프라인·UI 코드를 고치지 않는다. 폴더 구현만 존재(카메라 구현은 FR-01과 같이 미구현). 검증: 파이프라인 테스트가 가짜 소스(`ListSource`)로 동작.

### FR-03 전처리 — 부분
| 항목 | 내용 |
|---|---|
| 처리 | 컬러 로드 → 정사각 리사이즈(INTER_AREA) → RGB → /255 → ImageNet mean/std → CHW float |
| 수용 기준 | 출력 shape [3,N,N], 채널 순서 RGB, 손상 파일은 명확한 오류(파일명 포함), 한글 경로 지원, **학습 스크립트와 동일 전처리** |
| 상태 | 위 항목 구현. **ROI 지정·노이즈 제거는 미구현** |
| 검증 | `Preprocess_*` 테스트 3건, 파이썬 `test_common`, `OnnxParityTests`(파이썬↔C# 점수 오차 < 1e-4) |

### FR-04 AI 추론 — 구현(분류)
| 항목 | 내용 |
|---|---|
| 입력 | 전처리된 이미지 [1,3,H,W] |
| 처리 | ONNX Runtime(CPU)으로 분류 모델 실행. 출력 logits 2개를 softmax해 불량 확률 산출 (인덱스 0=양품, 1=불량) |
| 수용 기준 | 모델 파일 없음 → `FileNotFoundException`, 모델 버전 = 파일 SHA-256 앞 12자리 자동 기록 |
| 상태 | **분류 구현**. 검출(박스) 모델 파서, GPU 실행은 미구현 |
| 검증 | `OnnxMathTests` 5건, `OnnxParityTests`, 실제 모델(metal_nut) 시연 |

### FR-05 판정 — 구현
| 규칙 | 결과 |
|---|---|
| 불량 확률 ≥ 임계값 | NG (경계값 포함 — 미검출이 오검출보다 비용이 크다는 기준) |
| 불량 확률 < 임계값 | OK |
| 점수가 NaN/무한대, 이미지 손상, 추론 예외 | **ERROR**(양품으로 처리하지 않음), 사유 기록 |
| 검출 결과가 있는 경우 | 신뢰도 ≥ 임계값인 박스가 하나라도 있으면 NG |

검증: `JudgeTests`(경계값·ERROR·재판정), `PipelineTests`.

### FR-06 결과 표시 — 부분
| 상태 | 내용 |
|---|---|
| 구현 | 원본 이미지, OK/NG/ERROR 큰 표시(색상), 불량 점수, 처리시간, 누적 건수·양품률(OK÷(OK+NG)), 최근 결과 목록 |
| 미구현 | **원본 위 불량 위치(박스/히트맵) 오버레이**, 줌/팬 |

검증: 실제 화면 캡처 [01_검사화면_metal_nut.png](screenshots/01_검사화면_metal_nut.png).

### FR-07 이력 저장 — 구현
| 항목 | 내용 |
|---|---|
| 처리 | 검사 회차(모델·소스·임계값·상태)와 이미지별 결과(경로·판정·점수·처리시간·사유·시각)·불량 목록을 SQLite에 저장 |
| 수용 기준 | 저장 실패 시 검사는 계속하고 실패 건수를 요약에 표시. 이미지 파일은 DB에 넣지 않고 경로만 저장. 시각은 UTC |
| 검증 | `Roundtrip_*`, `Save_failure_is_counted_and_run_continues`, `Pipeline_end_to_end_*` |

### FR-08 이력 조회 — 부분
기간(로컬 날짜, 종료일 포함)·판정 필터, 최신순 최대 500건, 선택 시 이미지·상세 표시(이미지 파일이 이동·삭제됐으면 그 사실을 표시). **불량 유형·모델 버전 필터와 페이지 이동은 미구현.** 검증: `Time_filter_and_limit`, 이력 화면 캡처 [02_이력화면.png](screenshots/02_이력화면.png).

### FR-09 재판정·라벨 정정 — 구현(권한 구분 없음)
| 항목 | 내용 |
|---|---|
| 정정 | 목록에서 결과를 골라 **OK/NG로 정정**하고 메모(최대 500자)를 남긴다. 원 판정은 덮어쓰지 않고 `result_review`에 행을 추가하며, **가장 나중 정정이 유효**. 정정 이력은 오래된 순으로 표시 |
| 오판 표시 | 정정한 판정이 원 판정과 다르면 "⚠오판"(재학습·임계값 조정 후보), 같으면 "✓확인". "정정" 필터: 전체/정정 없음/정정됨/오판만 |
| 재판정(미리보기) | 임계값 슬라이더를 움직이면 **모델을 다시 돌리지 않고 저장된 점수로** 목록의 재판정 열과 "NG→OK n건, OK→NG m건 바뀜"을 즉시 계산. `ThresholdJudge`와 같은 규칙(점수 ≥ 임계값이면 NG), ERROR는 점수가 없어 제외. **저장된 판정은 바뀌지 않는다**(미리보기 전용) |
| 정정 기반 성능 | 정정된 건을 정답으로 보고 새 임계값의 재현율·정밀도·놓친 불량·오검출을 계산(표시된 건 기준, ERROR 제외). 정정이 없으면 계산 불가 안내 |
| 수용 기준 | 정정 값은 OK/NG만(ERROR 불가), 정정자 필수, 메모 500자 초과 불가, 존재하지 않는 결과는 거부(FK), 기존 DB도 열 때 새 테이블이 자동 생성, 한글 메모 보존 |
| 상태 | **구현**. 로그인(FR-12)이 없어 정정자는 Windows 사용자 이름이고 **역할별 권한 구분은 없음**. 정정 데이터의 재학습용 내보내기, 정정 취소(되돌리려면 반대로 다시 정정)는 미구현. 재판정 결과를 이력에 확정 저장하는 기능도 없음 |
| 검증 | `RejudgeTests`·`ReviewServiceTests`·`ReviewRepositoryTests`(19건), UI 자동화로 행 선택→메모 입력→정정 버튼→DB 저장→임계값 변경 확인, 화면 캡처 [04_재판정화면.png](screenshots/04_재판정화면.png) |

### FR-10 통계 — 구현(불량 유형은 검출 모델 전환 후 표시)
| 항목 | 내용 |
|---|---|
| 입력 | 기간(로컬 날짜, 종료일 포함, 비우면 전체) |
| 처리 | 저장된 결과를 집계: 총·OK·NG·ERROR, **양품률 = OK ÷ (OK + NG)**(ERROR는 판정 불능이라 분모에서 제외, 판정이 없으면 "-"), 일별 양품률(**로컬 달력 날짜 기준**, 검사가 없던 날은 표시하지 않음), 불량 유형별 건수, 처리시간(평균·p95·최대·구간 분포) |
| 처리시간 규칙 | OK/NG만 대상(ERROR는 실패가 빨라 분포를 왜곡). p95는 최근접 순위(정렬한 n개 중 ⌈0.95·n⌉번째, 보간 없음) |
| 출력 | 요약 카드, 일별·불량 유형·처리시간 막대, 평균·p95 문구 |
| 상태 | **구현**. 분류 모델은 불량 위치·유형을 내지 않아 `defect` 테이블이 비므로 "불량 유형" 영역은 비어 있고 안내 문구를 표시. 그래프 확대·내보내기·기간 프리셋은 미구현 |
| 검증 | `StatsCalculatorTests`(양품률·로컬 날짜 경계·p95·ERROR 제외·빈 데이터), `StatsRepositoryTests`(기간·불량 유형 집계), 화면 캡처 [03_통계화면.png](screenshots/03_통계화면.png) |

검사 화면의 양품률도 같은 규칙(`QualityMath.YieldRate`)을 쓴다.

### FR-11 설정 — 부분
임계값 슬라이더(0~1), 이미지 폴더·모델 파일 선택은 구현. **ROI, 저장 경로, 설정 영속화는 미구현**(실행 인자 `--folder --model --threshold --db`로 대체 지정 가능).

### FR-12 로그인·권한 — 미구현
작업자/엔지니어/관리자 구분, 감사 로그.

### FR-13 연속 검사 — 부분
생산자-소비자 파이프라인(큐 용량 제한, 워커 수, 취소)은 구현. **폴더 감시·카메라 연속 촬영 입력은 미구현**.

### FR-14 리포트 내보내기 — 미구현
CSV/PDF.
